第一部分：Render.com 公网部署

为什么选 Render？支持完整 Node.js 运行时，免费层包含 750 小时/月、自动 HTTPS、自动部署。比纯静态托管更适合我们的全栈应用。
1注册 GitHub 账号（已有跳过）

访问 github.com 注册，然后将项目目录推送到 GitHub 仓库。

cd /Users/mireia/WorkBuddy/2026-08-06-13-40-56
git init
git add .
git commit -m "GlowSelf - 颜值打分网站"
git remote add origin https://github.com/你的用户名/glowself.git
git push -u origin main

注意：确保 .gitignore 包含 node_modules/、data/、.env

2注册 Render 账号

访问 render.com，点击 "Get Started"，用 GitHub 账号登录。

3创建 Web Service
  • Dashboard → New + → Web Service
  • 选择你推送的 GitHub 仓库 glowself
  • Render 会自动识别 render.yaml 配置文件
  • 确认以下设置：
    • Runtime: Node
    • Build Command: npm install
    • Start Command: node server.js
    • Plan: Free

在 Render 的 "Environment" 标签页中，逐个添加以下变量：

5部署

点击 "Create Web Service"，Render 会自动构建并部署。部署完成后获得公网 URL：https://glowself-xxxx.onrender.com

✅ 至此网站已公网可访问！用户可以注册、上传照片、获取 AI 分析报告。新用户有 1 次免费体验。
关于免费层限制：Render 免费层在 15 分钟无请求后会休眠，首次访问需等待 ~30 秒冷启动。如需持续在线，可升级到 Starter 计划（$7/月）。数据库在免费层为临时存储，重新部署会丢失数据。如需持久化，建议升级到付费计划使用 Persistent Disk，或切换为外部数据库（如 Supabase 免费 PostgreSQL）。

第二部分：微信支付商户号申请

前提条件：微信支付商户号需要营业执照（个体工商户或企业均可）。以下为注册指引。
1注册个体工商户（已有跳过）
  • 成本低：注册免费，年报简单
  • 需要材料：身份证、经营场所证明（可用住宅地址）
  • 办理渠道：当地市场监督管理局 / 线上政务服务平台
  • 办理时间：通常 1-3 个工作日
  • 建议经营范围包含：信息技术服务、软件开发、互联网信息服务
2申请微信支付商户号
  • 访问 pay.weixin.qq.com → 点击"接入微信支付"
  • 选择主体类型：个体工商户
  • 提交材料：营业执照、法人身份证、结算银行卡
  • 选择支付场景：Native 支付（扫码支付，适合网页）
  • 审核时间：通常 1-5 个工作日
3获取支付凭证

商户号审核通过后，在微信支付商户平台获取以下信息：

凭证名称环境变量获取位置
商户号WXPAY_MCHID商户平台首页 → 账户中心
AppIDWXPAY_APPID需绑定公众号/小程序的 AppID
商户API证书序列号WXPAY_SERIAL_NO商户平台 → 账户中心 → API安全
商户API私钥WXPAY_PRIVATE_KEY下载API证书，提取 apiclient_key.pem
APIv3密钥WXPAY_API_V3_KEY商户平台 → 账户中心 → API安全 → 设置APIv3密钥
4配置支付回调地址

在微信支付商户平台设置 API 安全 → 添加回调地址：

https://你的应用名.onrender.com/api/payment/callback

同时在 Render 环境变量中设置 WXPAY_NOTIFY_URL 为上述地址。

第三部分：密钥配置与上线

1在 Render 中添加支付密钥

Render Dashboard → 你的 Web Service → Environment，添加：

WXPAY_MCHID=你的商户号
WXPAY_APPID=你的AppID
WXPAY_SERIAL_NO=证书序列号
WXPAY_PRIVATE_KEY=-----BEGIN PRIVATE KEY-----
你的商户私钥内容（多行）
-----END PRIVATE KEY-----
WXPAY_API_V3_KEY=你的APIv3密钥
WXPAY_NOTIFY_URL=https://你的应用名.onrender.com/api/payment/callback
2重新部署

修改任何环境变量后，Render 会自动触发重新部署。也可以手动触发：Dashboard → Manual Deploy → Deploy latest commit。

3验证支付

部署完成后，访问 /api/health 检查 paymentConfigured 是否为 true。

curl https://你的应用名.onrender.com/api/health
{"status":"ok","paymentConfigured":true}

然后用测试账号体验完整流程：注册 → 用完免费次数 → 扫码支付 1.99 元 → 获得新次数 → 继续分析。
