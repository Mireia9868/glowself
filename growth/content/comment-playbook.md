# 评论区回复手册

原则：先承认对方的担心，再给具体信息，不辩论、不承诺“最准”、不诱导消费。每条回复控制在 2–3 行。

| 质疑/问题 | 回复口径 |
|---|---|
| 又是智商税吧？ | 理解。我们不给你打分，也不卖“变美焦虑”。免费版就能拿到 12 个本命色和 3 套公式，先测完再看值不值。 |
| 要上传照片吗？ | 不用。11 个问题只问肤色倾向、颜色偏好和场景，不采集人脸，也不要求注册。 |
| 准不准？ | 它不是医学或专业色彩鉴定，是一套可执行的筛选规则。测完建议拿 3 件已有衣服对照色卡，在自然光下看脸是否更干净。 |
| 和韩国/线下色彩测试有什么区别？ | 线下强在面料、陪购和现场比对；我们强在免费、可重复、能每天用。两者不冲突，预算有限可以先做线上。 |
| 多少钱？ | 测试免费。Plus 内测 ¥39/月（年付 ¥299），包含完整报告、每日 look、衣橱和 30 天计划；现在只登记，不扣费。 |
| 免费报告有什么？ | 季型、风格坐标、12 个本命色、6 个靠近脸的颜色、3 套穿搭公式和一张分享卡。 |
| 为什么没有分数？ | 分数只告诉你“被排在第几”，不告诉你明天穿什么。我们更想给你一个能用的答案。 |
| 男生能用吗？ | 可以。色彩和风格的逻辑不分性别；目前文案和示例偏女性，但测试结果同样适用。 |
| 黑黄皮能穿亮色吗？ | 能，但要看冷暖、面积和位置。亮色放下半身或包鞋更稳，靠近脸时先试冷调亮色。 |
| 结果和我平时穿的完全不一样？ | 先别急着否定。拿色卡在自然光下对比下颌线，再看 3 套公式里有没有你已有的单品；也可能是你一直穿的是“安全色”，不是“本命色”。 |
| 会一直推销吗？ | 不会。留邮箱只用于内测通知和报告，随时可退订；不买 Plus 也能一直用免费版。 |
| 要多久？ | 11 个问题，大约 2 分 30 秒；不注册、不上传照片。 |
