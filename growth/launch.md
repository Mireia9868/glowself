# GlowSelf 上线手册 / Launch Playbook

> 目标：把 v2 从本机推到 `glowself.cn`，并在 7 天内拿到第一批 100 个测试完成、20 个分享、10 个邮箱线索。

## 1. 上线前检查（T-3 天）

### 产品
- [ ] 手机 390 / 430 宽度检查：首页、测试、结果、App、定价、文章；
- [ ] 完整跑一遍：首页 → 测试 11 题 → 结果 → 下载分享卡 → 复制链接 → 新窗口打开分享页；
- [ ] 无结果打开 `/app.html` 显示空状态，不报错；
- [ ] 结果页刷新后仍保留（localStorage `glow_result_v2`）；
- [ ] 分享页 `/r/cool-winter/elegant` 的 OG 图在微信/小红书预览正常；
- [ ] 所有表单有成功/失败提示，不出现 501/500；
- [ ] 404 页面正常，`/robots.txt`、`/sitemap.xml` 不是 SPA 首页；
- [ ] Lighthouse（移动）Performance ≥ 85、Accessibility ≥ 90。

### 数据
- [ ] `POST /api/events` 返回 `{ok:true}`；
- [ ] `POST /api/leads` 返回 `{ok:true,id}`；
- [ ] `GET /api/stats?key=...` 能按天看到事件；
- [ ] 清理测试数据：`data/events.ndjson`、`data/leads.ndjson`；
- [ ] 备份一份到 `data/backup/`（不要提交含邮箱的文件到公开仓库）。

### 合规
- [ ] 隐私页写明：不采集人脸、localStorage、匿名事件、IP/UA、24 个月保留、删除方式；
- [ ] 条款页写明：内测不收费、7 天无理由退款、2 次点击取消；
- [ ] 所有「AI」表述不承诺医疗/心理诊断；
- [ ] 支付上线前，确认主体、发票、退款流程。

### 域名 / 部署
- [ ] Cloudflare DNS 指向 Render；
- [ ] HTTPS 强制，`www` 301 到裸域；
- [ ] `ADMIN_KEY` 使用 32 位随机串，不写进前端；
- [ ] `DATA_DIR` 指向持久磁盘（Render Disk）；
- [ ] 设置 `LEADS_WEBHOOK_URL`（企业微信/飞书机器人）接收线索；
- [ ] 自定义 404、`og-cover.png`、favicon 可访问。

## 2. 部署（Render 推荐）

1. 把 `glowself/` 推到 GitHub 仓库；
2. Render → New → Web Service → 连接仓库；
3. Runtime: Node；Build Command 留空；Start Command: `node server.js`；
4. 环境变量：
   - `PORT=10000`（Render 自动注入，通常不用写）
   - `ADMIN_KEY=<32位随机>`
   - `DATA_DIR=/var/data`
   - `LEADS_WEBHOOK_URL=<飞书/企微 webhook>`
5. 添加 Disk：mount path `/var/data`，1 GB；
6. Health Check Path：`/api/health`；
7. 绑定 `glowself.cn`，Cloudflare 代理开启；
8. 验证：
   ```bash
   curl -s https://glowself.cn/api/health
   curl -s https://glowself.cn/robots.txt
   curl -s https://glowself.cn/sitemap.xml | head
   curl -s https://glowself.cn/r/cool-winter/elegant | grep og:title
   ```

> 免费实例没有持久磁盘，部署后事件会丢；上线必须用 Starter 及以上 + Disk。

## 7. 上线后 30 天节奏

- 每天：1 篇小红书 + 1 条抖音/视频号 + 数据记录；
- 每周：1 篇公众号深度 + 1 次直播答疑 + 1 次复盘；
- 每两周：1 个产品迭代（分享卡样式、结果准确性、每日 look）；
- 第 30 天：决定是否开启付费（Plus 年付 ¥299），用前 100 个邮箱做预售。

## 8. 回滚预案

- 部署失败：Render 保留上一个 deploy，一键回滚；
- 数据异常：`DATA_DIR` 快照恢复；事件文件按天备份；
- 舆情/隐私问题：立即下线相关页面，发说明，提供删除入口；
- 支付问题：内测期不收款，所有 CTA 改为「预约内测」，避免退款纠纷。
